## 📊 Dataset Information
- **Dataset:** Titanic — Machine Learning from Disaster  
- **Source:** Kaggle  
- **Size:** 891 rows, 12 columns  
- **Description:** Contains demographic and socioeconomic data of Titanic passengers used to analyze survival patterns.

---

## 🔥 Top 3 Survival Insights
1. **Gender is the strongest predictor:**  
   Females had ~74% survival rate vs ~19% for males.

2. **Passenger class matters:**  
   First-class passengers (~63%) survived more than third-class (~24%).

3. **Wealth impacts survival:**  
   Higher fare and cabin availability increased survival chances.
